# Учебный каталог книг

Этот репозиторий используется в [лабораторной работе № 3](https://course.denrad.dev/materials/lab-03/): студент предлагает новую карточку книги через fork и pull request.

## Как устроен каталог

- `books/` — отдельный Markdown-файл для каждой книги;
- `BOOK_TEMPLATE.md` — образец полей карточки;
- `.gitignore` — правило для локальных черновиков в `scratch/`.

Пример карточки находится в [`books/example.md`](books/example.md). Прежде чем создавать свою карточку, получите номер или тему у преподавателя. Назовите файл по этому номеру, например `books/book-17.md`, и заполните его по шаблону. Не меняйте чужие карточки без задания и не добавляйте настоящие пароли, токены или личные данные.

Откройте pull request из ветки своего fork в основную ветку этого репозитория. После замечания преподавателя исправьте тот же файл, сделайте новый коммит и отправьте его в ту же ветку: открытый pull request обновится.
